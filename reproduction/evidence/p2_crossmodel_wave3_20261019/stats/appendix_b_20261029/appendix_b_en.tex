\paragraph{Software.} Local runs use PyTorch (2.5.1 to 2.11.0) and Hugging Face Transformers (5.8.0 or 5.19.0); the identity file of each run in the data package records the versions it used. DeepSeek-V4.1-Flash has no Transformers implementation and runs on the model code of its release, with the custom kernels of the release replaced by PyTorch implementations of the same arithmetic and the weights kept in the release format (FP8, with FP4 expert weights). Both Ministral-3-14B models run in BF16.

\paragraph{Decoding and APIs.} In thinking mode, local runs generate greedily, up to 4,096 tokens for Qwen3.8-27B in Section~\ref{sec:res_thinking} and up to 3,072 tokens elsewhere. The thinking-mode self-reference of two models comes from the developer's API with the same inputs: GLM-5.3-Flash through the Z.ai API (model \texttt{glm-5.3-flash}, temperature 0, at most 3,072 tokens), and DeepSeek-V4.1-Flash through the DeepSeek API (model \texttt{deepseek-flash}, which the provider documents as served by DeepSeek-V4.1-Flash-1017; reasoning effort high, temperature 1.0 and top-$p$ 1.0, the settings the developer recommends, since the thinking mode offers no greedy decoding; at most 3,072 tokens). For every request, the number of prompt tokens reported by the API equals that of the local rendering.

\paragraph{Statistics.} All intervals are 95\% intervals with a fixed seed: percentile bootstrap intervals over wording families for the geometry (1,000 resamples), over bodies or items elsewhere (4,000 to 10,000 resamples), and over models for the rank correlations of Appendix~\ref{app:benchmarks} (10,000 resamples); the shares of finished items in Figure~\ref{fig:self_mechanism} carry Wilson intervals. Each subspace of the replacement is fitted on the discovery bodies and stored with the random subspace of its control (the orthonormalized columns of a Gaussian matrix, drawn per layer with a fixed seed); every test that uses it reads the stored coordinates.
